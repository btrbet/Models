# BtrBet Betting Models

This repository is a collection of betting models for various sports betting markets, created and shared by the BtrBet team.

## About This Repository

This repo contains Python models and scripts for analyzing and predicting outcomes in various betting markets. The models are organized by sport and are intended to be illustrative. You should use them as inspiration to build your own betting models as these might not be profitable as written.

### Current Models

- **MLB**
  - `pitching_ks_per_game.py`: Analyzes and predicts strikeouts per game for pitchers

More models and markets will be added over time.

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/your-org/Models.git
   cd Models
   ```
2. Navigate to the directory for the sport you're interested in:
   ```bash
   cd MLB
   ```

3. Activate the python virtual environment:
   ```bash
   source venv/bin/activate
   ```

4. Install dependencies for each model (see the `requirements.txt` in each subdirectory):
   ```bash
   pip install -r requirements.txt
   ```

5. Run the scripts as described in their respective README files or script docstrings.
